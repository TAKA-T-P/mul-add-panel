# かけ×たし+パネル

「積と和で解くロジックゲーム」。静的な HTML/CSS/JavaScript で作る数字パズルです。
ブラウザ上で遊べ、GitHub Pages でもそのまま公開できます。

## 使い方
1. `index.html` をブラウザで開く（ローカルで `fetch` を使うため、`file://` で問題データが読めない場合は
   `npx serve .` などの簡易サーバー経由で開いてください）
2. タイトル画面から「イージー」「スタンダード」「3分チャレンジ」を選ぶ
3. イージー／スタンダードでは「じっくり」「1問タイムアタック」「3問タイムアタック」を選べる

## 仕様概要
- 盤面：イージー(3列×2行・1〜6)／スタンダード(3列×3行・1〜9)
- 横一列は数字の「積」、縦一列は数字の「和」が外側の数と一致すれば正解
- 出題は全問一意解（`tools/generate-puzzles.js` で全探索して生成）
- 数字はドラッグ＆ドロップ（Pointer Events）、またはタップで配置・入れかえ可能
- じっくりのみヒント使用可（最大3回、正解の数字を1マス開示して固定）
- 1問／3問タイムアタックは自己ベストを、3分チャレンジはクリア数・連続ノーミス記録などを
  `localStorage` に保存
- 1問／3問タイムアタックでは、クリア時間に応じて
  MAX・SS・S・A・B・C・D・E・Fの9段階評価、称号、褒めコメントを表示。
  評価基準は、イージーが1問10秒、スタンダードが1問40秒を基準とし、
  3問モードは1問あたりの平均時間で判定
- 3分チャレンジは固定マスが 5→4→3→2→1 と段階的に減り、時間切れ後は最終問題として
  30秒の猶予が与えられ、クリア数に応じた称号・褒めテキストを表示
- 効果音（Web Audio による短い合成音）と数字パネルの色を設定画面で切り替え可能

## 問題データの生成
```bash
node tools/generate-puzzles.js
```
`data/puzzles-3x2.json`（100問以上）・`data/puzzles-3x3.json`（300問以上）を再生成します。
生成時に一意解であることを全探索で確認し、各クレイズ（積・和）の候補数の多さから簡易的な
難易度スコア（1〜5）を付与、極端に簡単・難しい問題に偏らないよう階層ごとに均等サンプリングしています。

## ディレクトリ構成
```text
index.html
css/style.css
js/app.js       画面遷移・状態管理・演出
js/puzzle.js    盤面定義・一意解判定・固定マス配置
js/storage.js   localStorage 読み書き
js/timer.js     経過時間タイマー／3分チャレンジ用カウントダウン
data/           生成済み問題データ
tools/generate-puzzles.js  問題データ生成スクリプト
assets/icons, assets/sounds  将来アイコン・音声ファイルを追加する場合の置き場（現状未使用）
```
